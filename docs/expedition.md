# 归梦小院与药水

更新日期：2026-09-21。详细数值与策划理由见[药水与归梦小院](../塔防割草小游戏策划/14_药水与归梦小院.md)。

## 已接入

- 主场景启动显示归梦小院，战斗计时、移动和刷怪暂停；点击「开始守镇」才开始。
- 梦砂初始为0，怪物独立概率掉落，拾取后存入本地存档。返回小院保留已拾取梦砂，未拾取掉落和本局药水清空。
- 逐风灵契60梦砂、移动速度+12%；藏露灵契80梦砂、药水栏2→3；回响灵契100梦砂、常驻技能冷却和气刃伤害间隔×0.9。购买永久解锁，每局最多装备一件，购买后单独点击携带。
- 基础药水栏2格，每格一瓶；怪物掉落风涡、凝霜、回春、地裂、唤雨五种灵露。满栏时药水留在地面，经验和梦砂仍正常拾取。
- 当前开局配置：每局点击「开始守镇」后，第一格携带一瓶地裂灵露，第二格携带一瓶唤雨灵露，可直接点击使用；藏露灵契的第三格留空。
- 点击药水暂停并显示「使用／丢弃／取消」。成功使用才消耗；满血回春和已有龙卷风时再用风涡均保留原瓶。丢弃直接销毁，取消保留；共用1秒使用间隔，只按有效战斗时间计时。
- 风涡持续5秒、同屏最多1个；凝霜冻结普通怪1.5秒、随后减速2秒，精英只减速、Boss免控；回春恢复最大生命30%。药水伤害不消耗余势。
- 地裂在使用时自动瞄准附近敌人，优先选择预计覆盖更多怪物的方向、同数量优先近敌；无目标时沿角色朝向释放，施放后方向锁定。距角色32开始，总长2000、主命中宽480（圆端区域）。0.48秒裂开时结算一次，秒杀普通怪、精英和Boss，保留正常击杀统计与掉落；带撕裂声、重击轰鸣和短促震屏，2.8秒后消失，残留期间不持续杀怪，同屏最多一道。
- 唤雨在0.35秒起势后全屏降雨6秒，每0.5秒造成使用时150%攻击伤害，共12次，最后0.45秒只淡出。范围随视野移动，包含精英与Boss；同屏最多一场，暂停同步停止计时、雨幕与雨声。说明、资源和验证见[唤雨灵露](rain-potion.md)。药水掉落总概率不变，种类权重为回春40%、风涡15%、凝霜15%、地裂15%、唤雨15%。
- 秘籍里的「领取地裂」可在有空栏时领取一瓶；关闭秘籍，再点击药水栏使用，会自动选择攻击方向。
- 正式学习池为基础射击、穿透箭、气刃环、自动落雷、连锁闪电，仍使用3技能槽和本局一次进化。风系与寒霜的原实现保留给调试入口，风眼核心在正式对局中因前置不满足退出候选池。
- HUD增加本局梦砂、灵契、药水栏和返回小院入口。主动返回先显示本局清空说明；角色倒下后也可返回。

## 文件与资源

- `HomePanel.prefab`、`ExpeditionHud.prefab`、`PotionMenu.prefab` 位于 `assets/Resource/UI`；界面节点保存在Prefab中，由脚本绑定事件与更新数据。
- `PotionDrop.prefab`、`DreamSandDrop.prefab` 位于 `assets/prefabs/loot`，根节点Sprite提供批量绘制的图片、尺寸和颜色。
- 两张新透明PNG位于 `assets/art/loot`：`potion_bottle.png` 与 `dream_sand.png`。药水复用同一瓶图并按种类染色，梦砂使用独立星砂图案。均通过Asset DB配置Sprite导入并验证真实SpriteFrame UUID。
- 地裂使用 `EarthRiftEffect.prefab`、`earth-rift.mtl` 与 `earth-rift.effect`。一个复用Sprite、一份独立材质、每瓶一次瞄准查询和一次命中查询，最多比较32个候选方向；不使用粒子、屏幕抓取或额外渲染目标。独立材质从预制体材质复制并绑定到 `customMaterial`，由地裂效果负责销毁；不能在尚未激活的Sprite上缓存 `getMaterialInstance(0)`，也不能跨禁用周期复用渲染器清理掉的实例。新版使用imagegen制作的透明裂缝图 `earth_rift_chasm.png`，Shader控制沿线撕开、岩岸错动、命中闪光和淡出。贴图、音效来源、性能约束及提示词见[地裂效果说明](earth-rift.md)。
- 掉落仍使用512个地面记录上限与批量绘制，新增两组预置绘制节点；合并药水按类型区分，拾取后保留未被收取的合并瓶数。
- 局外状态使用 `guarding-town:expedition:v1` 本地存档。余额、解锁和装备一并写入，失败时不发布扣款或入账变更；暂不包含云存档和跨设备同步。
