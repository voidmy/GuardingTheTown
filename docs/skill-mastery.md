# 技能秘籍与永久研习

更新：2026-09-22。规则已接入，数值为首版试调值，尚未完成微信真机留存与平衡验证。

## 玩家链路

初始掌握基础射击、气刃环 → 小院指定一个未掌握技能优先研习 → 战斗拾取青色秘籍宝匣 → 本局领悟并使用 → 保存研习 → 永久掌握后可选为本命、进入普通学习池。

- 小院继续显示六种有完整资源的常驻技能。已掌握的可以选本命，未掌握的显示当前研习与目标值，按钮为「优先研习」。默认优先刀气起；设置优先研习不会改变已选本命。
- 开局仍只有所选本命 Lv.1，三个技能槽、局内 Lv.1～5、唯一进化、两枚核心和十三次普通升级保持原有规则。
- 普通选卡中的新技能只来自已永久掌握的技能。通过秘籍领悟的技能可以正常升级和进化。本命强化仍保底；前期技能候选不足三项时允许火力、强健补位。
- 有效战斗时间 60 秒、180 秒，各在玩家附近出现一次秘籍宝匣。优先发放所选研习目标；目标已掌握或资源不可用时，按刀气起、落雷、穿透箭、连锁闪电寻找下一个可用未掌握目标。全部掌握后不再发秘籍，其他补给保持原样。
- 拾取秘籍时有空槽则立即领悟对应技能 Lv.1，不消耗普通选卡次数；同一技能重复拾取不重复占槽、不自动加级。满槽时保留现有构筑，仅获得研习，提示「技能槽已满，仅增加研习」。地面未拾取秘籍不结算。
- HUD 标明「本局领悟」和研习进度；临时技能在本局达到永久掌握后标明「已掌握」。回小院后可以选作本命，下一局仍从 Lv.1 开始。

## 研习数值

| 项目 | 首版值 |
| --- | --- |
| 第一种拾取秘籍的技能 | 60 点掌握 |
| 其余技能 | 每种 180 点掌握 |
| 每本秘籍 | +20 点，达到目标后封顶 |
| 使用技能 | 每个 2 秒有效战斗区间内，有实际有效伤害则该技能 +1 点 |
| 进度保存 | 秘籍拾取立即保存；命中进度每 10 秒批量保存；死亡、胜利、主动返回、切后台时补存 |

第一种技能以首次成功拾取秘籍为准，不会通过切换优先研习反复获得 60 点优惠。首次拾取前，各未掌握技能显示首个目标 60；确定首个目标后，其余显示 180。

命中研习只对通过本局秘籍获得的技能生效。范围攻击、连锁命中、同一时间大量怪物不会按目标数刷进度；未命中、空等、选卡、药水菜单、暂停和纯调试获得技能不产生研习。技能冷却与战场目标会影响实际速度，不承诺固定几分钟掌握。

死亡和主动返回不扣已获得研习，不要求通关。两次秘籍补给提供稳定积累，即使技能栏满或操作不熟练，也能跨局推进。

## 存档与性能

- 新存档键 `guarding-town:skill-mastery:v1`，独立保存各技能进度、首个目标与优先研习。已有梦砂、灵契、药水携带配置不改写；旧配置中的未掌握本命会被清空，需要重新选择基础技能。
- 写入成功后才发布永久进度。秘籍写入失败不消费掉落，五秒后允许重试；定时保存失败保留本局待保存量，返回小院前重试。无法读取或不支持的存档保留原文，不覆盖为新档。
- 热路径只设置命中位标记，每两秒处理固定四种技能，避免每次命中或每只怪物写存档。
- 秘籍宝匣复用现有宝箱 PNG、SpriteFrame、音效和批量绘制节点，以青色物品与光柱区分；没有新增图片、材质、UI 节点或逐物品实例。掉落合并增加技能 ID 条件，防止不同秘籍混合。
- 小院、HUD、结算复用既有 Prefab 节点；结算研究明细最多两行，保存状态使用现有状态栏。
