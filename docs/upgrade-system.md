# 升级系统与秘籍

2026-09-20补充：游戏先进入归梦小院，购买／装备灵契后开始战斗。正式学习池保留五种常驻技能，风系与寒霜转为药水，调试入口保留七种。药水、梦砂、局外存档和新页面见[归梦小院与药水](expedition.md)；下文七技能说明属于此前接入记录。

本局成长规则由 `assets/scripts/progression/RunProgression.ts` 管理，技能和核心文案放在 `UpgradeDefinitions.ts`。`MonsterCrowdController` 接收击杀、掉落拾取、计时与选卡结果，负责将成长状态同步到真实战斗参数。

正式HUD与新增自动技能见[战斗HUD与自动技能](hud-skills.md)。技能池现为7种，普通对局仍只有3槽；新增自动落雷、连锁闪电、寒霜脉冲，均支持Lv.1～5和一次进化。焰符阵继续保留为候选。

## 普通升级

- 开局一个本命技能，占3个普通技能槽之一；技能上限Lv.5。
- 怪物死亡后在原地掉落经验晶石，拾取时才增加经验：普通怪1、精英20、Boss 50；三类数值可在 `MonsterCrowdController` 中调整。所需经验为20、25、30……80，整局最多13次普通升级，溢出经验可连续产生待领取奖励。
- 每次三选一：已有技能下一等级、新技能、火力、强健或缺血时的恢复。槽满不再出现新技能，满级不再出现该技能升级。
- 每局3次整组刷新，普通与核心共享；刷新保持适用保底，不扣除无法产生新组合的次数。
- 第一枚核心在60秒有效战斗时间发放；第二枚在210秒且至少击败一次精英后发放。6枚核心有前置与互斥，最多持有2枚。
- 首次击败精英掉落会轻微脉动的特殊晶石，拾取后获得进化资格及15%最大生命恢复；任一技能Lv.5即可选择一次进化，也可以暂存后从HUD入口打开。
- 选卡、秘籍与进化共用战斗暂停；角色死亡取消未领取奖励并停止战斗。升级应用失败时保留奖励，不跳过。

本次实现沿用当前怪物与波次配置。策划中Boss前12次升级、3:00～3:30进化以及570经验投放量仍是后续波次调试目标，不代表当前波次已完成平衡标定。

## 死亡掉落与拾取

- `LootDropModel` 保存掉落和吸附状态，`LootDropSystem` 从预制体根节点读取图片外观，由 `LootBatchRenderer` / `LootBatchAssembler` 统一绘制PNG四边形。场景 `LootLayer` 下预置六个绘制节点，不实例化每颗掉落。同贴图物品合批，五种独立图片最多五批，光效单独一批并先绘制。图片与拾取判定共享掉落层坐标，提交顶点时转换到世界坐标。
- 普通、精英、Boss 分别使用青色水晶、紫晶、金色灵珠；宝箱、装备各有独立PNG。尺寸、预制体和替换步骤见 `docs/loot-art.md`。合并后的物品略大，首次精英掉落轻微脉动。稀有物品有金色/紫色光圈光柱，最多24处，吸附时停止光效。
- 每次击杀保留基础经验掉落，另独立判定宝箱和装备；可以同时掉落。默认普通怪宝箱0.8%、装备0.2%；精英乘5，即4%/1%；Boss乘10，即8%/2%。控制组件可调整两个概率和两个倍率，最终概率限制在0～100%。
- 宝箱拾取后，缺血时50%概率恢复25%最大生命，否则获得20经验。经验升级已达上限时，经验奖励改为15%最大生命护盾。装备拾取后随机提升一次已拥有技能、火力或强健，遵守现有Lv.5和属性3阶上限；无可用强化时改为同样的护盾。掉落护盾最多累积15%最大生命，遵守全局25%护盾上限，由伤害消耗，不计时消失；提示显示实际增加量，已满时明确提示。均直接作用于本局，不进入背包，不消耗待选升级奖励。HUD显示4秒拾取提示。
- 默认落地等待0.3秒，进入角色130范围后吸附，抵达22范围才结算；吸附速度从520逐渐加速。这些参数都可在掉落层组件中调整。
- 掉落不超时消失。场上最多512个；达到上限时合并同奖励种类、同怪物档次、同进化及吸附状态的旧掉落，保留经验总量与稀有奖励份数，新物品仍落在本次死亡位置。屏幕边界外的死亡位置会限制到可拾取的战场范围。
- 击杀数和“余势”仍在死亡时累计，第二枚计时核心的精英击败条件也在死亡时满足。经验、首次精英进化资格与回血在拾取时结算；同一帧拾取完成后统一处理升级选卡。
- 选卡、秘籍与角色死亡均停止掉落移动和拾取；重开场景清空掉落。拾取时图片消失，经验条即时刷新。每个绘制节点一次预留512颗的顶点与索引缓冲，未使用部分收拢为透明零面积三角形，增减掉落时不创建节点或重新分配顶点缓冲。

气刃环的默认环绕距离由原来的约 145 调整为 Lv.1 的 190，每升一级增加 15：Lv.1～5 分别为 190、205、220、235、250，进化后保持 250。角色控制组件可调整初始距离和每级增量；刀身大小、单刃命中半径及同周期对同怪去重规则保持不变。升级、降级时画面位置与伤害判定同步更新。

## HUD秘籍

点击HUD的“秘籍”按钮打开 `Resource` Bundle 中的 `UI/CheatPanel`。关闭后继续战斗，若有待领取成长奖励则先处理奖励。

- “获得”即时添加对应技能；加减按钮设置Lv.0～5，Lv.0移除技能，本命最低Lv.1。
- “全部满级”可同时持有八个Lv.5技能（包含刀气起）；此限制放宽只用于秘籍，普通卡池仍按3槽过滤。HUD显示“调试超额”，详细技能可在数值详情和秘籍中查看；进化面板在超额测试时支持八项分两行显示。
- 领取进化资格后，可以将任一Lv.5技能进化；本局仍只消耗一次进化机会。
- 反复调级会按目标等级重新计算参数并清理该技能旧实体，不累计之前等级的加成；其他技能的实体和计时保留。
- 所有修改仅作用于当前对局；重新运行场景恢复开局配置。

正式HUD显示生命、护盾、角色等级、经验条、有效战斗时间、击败数和3个技能槽。槽内显示图标、名称、本命标记、等级与进化状态，空槽提示“升级时学习”。FPS、怪物计数和秘籍保留；“数值详情”展开原来的完整技能、核心、刷新次数与战斗状态信息。

当前默认开启角色组件 `CharacterStats` 的“测试：零血量不死亡”。血量可以降到0，但仍能移动、攻击、升级和恢复生命，不触发死亡结束。取消该勾选即可恢复正常死亡规则；修改代码后需重新运行场景。
