# 升级系统与秘籍

本局成长规则由 `assets/scripts/progression/RunProgression.ts` 管理，技能和核心文案放在 `UpgradeDefinitions.ts`。`MonsterCrowdController` 接收击杀、计时与选卡结果，负责将成长状态同步到真实战斗参数。

## 普通升级

- 开局一个本命技能，占3个普通技能槽之一；技能上限Lv.5。
- 击杀普通怪直接获得1经验，精英20经验；所需经验为20、25、30……80，整局最多13次普通升级，溢出经验可连续产生待领取奖励。
- 每次三选一：已有技能下一等级、新技能、火力、强健或缺血时的恢复。槽满不再出现新技能，满级不再出现该技能升级。
- 每局3次整组刷新，普通与核心共享；刷新保持适用保底，不扣除无法产生新组合的次数。
- 第一枚核心在60秒有效战斗时间发放；第二枚在210秒且至少击败一次精英后发放。6枚核心有前置与互斥，最多持有2枚。
- 首次击败精英获得进化资格及15%最大生命恢复；任一技能Lv.5即可选择一次进化，也可以暂存后从HUD入口打开。
- 选卡、秘籍与进化共用战斗暂停；角色死亡取消未领取奖励并停止战斗。升级应用失败时保留奖励，不跳过。

本次实现沿用当前怪物与波次配置。策划中Boss前12次升级、3:00～3:30进化以及570经验投放量仍是后续波次调试目标，不代表当前波次已完成平衡标定。

## HUD秘籍

点击HUD的“秘籍”按钮打开 `Resource` Bundle 中的 `UI/CheatPanel`。关闭后继续战斗，若有待领取成长奖励则先处理奖励。

- “获得”即时添加对应技能；加减按钮设置Lv.0～5，Lv.0移除技能，本命最低Lv.1。
- “全部满级”可同时持有四个Lv.5技能；此限制放宽只用于秘籍，普通卡池仍按3槽过滤。
- 领取进化资格后，可以将任一Lv.5技能进化；本局仍只消耗一次进化机会。
- 反复调级会按目标等级重新计算参数并清理该技能旧实体，不累计之前等级的加成；其他技能的实体和计时保留。
- 所有修改仅作用于当前对局；重新运行场景恢复开局配置。

HUD同时显示角色等级、经验、技能等级、核心、刷新次数、护盾、专注层数与余势状态。

当前默认开启角色组件 `CharacterStats` 的“测试：零血量不死亡”。血量可以降到0，但仍能移动、攻击、升级和恢复生命，不触发死亡结束。取消该勾选即可恢复正常死亡规则；修改代码后需重新运行场景。

## 资源与验证

界面节点来自Prefab；新增或修改Prefab通过项目Cocos MCP完成，运行时只实例化资源。技能进化的气刃使用Prefab中预置的6个刃节点。

验证使用TypeScript检查、临时内存行为校验与编辑器资源引用检查；没有新增或修改测试文件，不进行截图。
