# 启程秘典

更新日期：2026-09-22。

开局与返回小院后的配置界面。先择本命、备灵露、结灵契，再点击「携卷出发 · 开始守镇」。停留在界面时战斗保持暂停。

## 配置规则

- **本命技能**：显示基础射击、穿透箭、气刃环、自动落雷、连锁闪电、刀气起中资源完整的技能；初始只掌握基础射击和气刃环，其余可以设为优先研习，掌握后才可选本命。开局装备所选技能 Lv.1，占用一个技能槽，另外两个槽留给局内学习或秘籍领悟。首次使用不预选，未选本命时禁止出发；原 GameSettings.initialSkills 保留作旧场景数据，不再控制开局。详见[秘籍与永久研习](skill-mastery.md)。
- **随行灵露**：先点击栏位，再选择灵露。五种灵露免费补给，每格一瓶，允许重复、留空及全部清空。基础两格，藏露灵契开放第三格。卸下藏露时第三格不带入本局，再装备可恢复该格偏好。
- **守镇灵契**：沿用梦砂购买、永久解锁和每局一件的规则，购买后再点击携带；也可以不带灵契。
- 底部持续显示本命、灵契与按栏位排序的灵露。选择即时保存在独立的 `guarding-town:loadout:v1` 本地配置中，不修改梦砂/解锁存档；不可用的旧技能或灵露会清空。存储失败时提示无法记住配置，仍可使用当前选择出发。
- 出发时重新检查技能资源、灵契所有权与药水容量，配置失效时留在界面给出原因并允许重试。成功出发后屏蔽重复调用，避免重复应用灵契。

正式关卡沿用玩家主动配置的灵露，不额外赠送。默认栏位仍为空；本命Lv.1、另两技能槽为空。关卡流程见[正式关卡与成长节奏](formal-chapter.md)。

## 实现与资源

- 所有界面节点保存在 `assets/Resource/UI/HomePanel.prefab`。复用原卡框、按钮和现有 PNG 图标，通过 Asset DB 确认真实 SpriteFrame UUID 后绑定，没有新增图片。
- 三张卡片在三个分页间复用，仅切页或修改选择时更新；无逐帧刷新和运行时创建 UI 节点。图标按原始比例适配。
- `HomePanel.ts` 负责展示与交互，`ExpeditionLoadout.ts` 负责携带配置，`MonsterCrowdController.ts` 在出发时初始化技能成长和药水栏。原灵契存档继续由 `MetaProgress.ts` 管理。
