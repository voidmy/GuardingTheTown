# 苔石拳王 · 龙骨工程

已根据确认的概念图完成部件拆分、骨骼绑定与关键帧制作，并在 DragonBones Pro 5.6.3 中保存为真实工程。

## 打开与预览

直接打开 `project/MossStoneKing.dbproj`。移动工程时保留同目录 `library/`；`MossStoneKing-DragonBones-project.zip` 已一起打包。

切到「动画制作」，在右下角「动画」列表选 `attack`，点击时间轴播放按钮，即可循环查看「蓄力 → 砸地 → 恢复」。左侧「默认播放」用于设置默认动画，不会替代右下角的编辑动画选择。

| 动画 | 时长 | 播放与表现 |
| --- | --- | --- |
| `idle` | 2.4 秒 | 循环待机，轻微身体起伏 |
| `walk` | 1.2 秒 | 循环迈步，拳头小幅摆动 |
| `enter` | 1.2 秒 | 下落落地、短促回稳 |
| `charge` | 1.2 秒 | 下沉准备，双拳抬高并停住 |
| `slam` | 0.9 秒 | 快速砸拳，地面震波扩散并淡出 |
| `recover` | 1.8 秒 | 低姿势停顿，逐渐直身放下手臂 |
| `death` | 1.4 秒 | 踉跄下沉、低头、全身淡出 |
| `attack` | 3.9 秒 | 完整攻击循环，由相同的 charge / slam / recover 关键帧组合 |

默认播放 `idle`。`charge` 的末尾姿势与 `slam` 开头一致，`slam` 末尾与 `recover` 开头一致。独立 `slam` 是从举拳结束姿势开始；查看完整动作优先用 `attack`。

## Cocos Prefab

已导入 Cocos Creator 3.8.8，并保存为 `assets/prefabs/bosses/MossStoneKing.prefab`。骨骼、图集配置和 PNG 位于 `assets/art/bosses/moss_stone_king/`。

根节点已挂载 `dragonBones.ArmatureDisplay`，骨架选择 `MossStoneKing`，默认 `idle` 无限循环，启用 `SHARED_CACHE` 和 `Enable Batch`。在组件的 Animation 下拉框中选择 `attack`，可以查看完整攻击循环；运行时可通过 `playAnimation('attack', 0)` 播放循环，或 `playAnimation('slam', 1)` 播放单次砸地。

Prefab 可拖入现有游戏的 `UIRoot/Background`。本次只导入动画资源和 Prefab，碰撞、伤害、生成调度仍需由玩法逻辑接入。`slam_impact` 只是资源中的时机标记，当前没有监听或触发伤害。

已保存并重新打开 Prefab，确认 8 个动画枚举、默认待机、缓存设置及两项龙骨资源引用保留正常。引用的资源 UUID 和纹理 sub-asset 通过 Asset DB 查询确认；Prefab 内部对象索引有效。游戏场景文件未改动，未启动 Cocos Preview。

## 结构

- 角色 7 根骨骼：root、body、head、arm_l、arm_r、foot_l、foot_r；震波单独 1 根，总计 8 根。
- 手臂与拳头各为一张整体贴图，不使用手指、肘部链、网格权重或 IK。
- 7 张图片放在一张 512 × 512 透明 PNG 图集内。苔藓、眉眼和胸前晶石直接画在部件上。
- 手臂图片用中心 pivot 加局部位移记录肩部转轴，兼容 DragonBones Pro 导入时对 pivot 的规范化。
- `slam_impact` 帧事件：`slam` 第 5 帧（约 0.167 秒）；`attack` 第 41 帧（约 1.367 秒）。事件只标记表现时机，不会自动造成游戏伤害。
- 图中震波仅为动画表现。Cocos 资源和 Prefab 已导入，碰撞或 Boss 战斗逻辑尚未接入。

## 文件

- `project/MossStoneKing.dbproj`：桌面编辑器保存的工程。
- `project/library/`：工程所需图集，请随工程移动。
- `project/MossStoneKing_ske.json`、`MossStoneKing_tex.json`、`MossStoneKing_tex.png`：从桌面编辑器导出的 DragonBones 5.5 运行数据。
- `MossStoneKing-DragonBones-import.zip`：可重新导入龙骨的源数据包。
- `source/`：图像生成源图、提示词、裁剪区域记录和数据验证结果。
- `parts/`：拆分后的透明 PNG 部件。
- `build_dragonbones.py`：确定性裁剪打包和关键帧生成脚本；不会替代或直接写入 `.dbproj`。
