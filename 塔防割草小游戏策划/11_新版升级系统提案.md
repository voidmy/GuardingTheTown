# 新版升级系统提案：技能成长＋核心定向＋精英进化

整理日期：2026-09-07

实施更新：局内升级、核心、进化与HUD秘籍已按本文接入，使用方式和当前实现边界见[升级系统与秘籍](../docs/upgrade-system.md)。本文的波次投放量、成长时间与平衡数值继续作为试玩调试目标。

**状态：供评审的新候选，尚未接入游戏。** 本文收敛[10版方案](10_技能构筑与普通升级.md)，并补充代码差距。没有防御塔是已确认约束；技能槽、次数、数值、时间均为本轮建议，不作为用户已确认决定。

## 1. 玩家一局会经历什么

开局带一个本命技能 → 击杀升级三选一 → 逐渐组成三个技能 → 两次核心选择确定打法 → 击败中途精英获得进化资格 → 将一个满级技能进化 → 用成型构筑挑战最终Boss。

建议先验证这一套：**3个技能槽、每技能5级、2个核心位、每局1次进化。** 四个技能足够验证首版，先让每次投入有价值。

| 内容 | 本轮候选规则 |
| --- | --- |
| 本命技能 | 开局Lv.1，占一个技能槽，本局不可卸下 |
| 副技能 | 普通升级学习，最多再学两个；学习后本局不可替换 |
| 普通升级 | 三选一；已有技能升级、学习新技能、通用属性共池 |
| 普通升级次数 | Boss前目标12次，整局最多13次；由经验获得，时间到不直接送升级 |
| 技能关键点 | Lv.2打基础，Lv.3固定机制变化，Lv.4～5继续加强 |
| 核心符文 | 有效战斗时间1:00、3:30各一次，三选一；最多2枚，不重复、不替换 |
| 进化 | 精英资格＋技能Lv.5，无隐藏配方；替换原技能，每局一次 |
| 刷新 | 每局3次整组刷新，普通与核心共用；进化不随机、不刷新 |
| 临时掉落、局外养成 | 后续独立设计，不影响本轮闭环 |

角色等级与技能等级分开显示。例如角色Lv.7代表完成6次普通升级，气刃Lv.3代表在该技能上投入过2次。核心和进化不增加角色等级。

## 2. 相比10版，这次具体改什么

1. **取消独立分支二选一。** Lv.3直接产生固定变化；分支不再增加弹窗和选择次数。六个核心承担打法差异，四技能各做一种进化。
2. **把12～14次模糊目标收敛成Boss前12次、全局最多13次。** 明确经验阈值和波次资源预算，再用试玩调整。
3. **补主修展示保底。** 保证认真投入一个技能的人有机会及时满级，不能只保证任意已有技能出现。
4. **进化可以暂存。** 满足条件时能主动选择，也能等另一个技能满级；资格不会被第一个满级技能自动消耗。
5. **卡片采用同一品质。** 展示本次变化、技能职责和代价；不把学习龙卷风放进一个天然更强的“金卡位置”。

正常局约15次选择：12次普通＋2次核心＋1次进化；Boss战额外升一级时最多16次。刷新是额外操作，要一并记录选择耗时。按每次思考5秒估算，实际总游玩可能约7分钟以上，不能把“6分钟战斗”当成“6分钟总时长”。

## 3. 四个技能的成长草案

以下是**可配置的第一轮参数草案，不是平衡结论**。每个技能独立配置Lv.1基础伤害D、基础间隔T；D不是四个技能共用的同一个数。表内指定的值均是相对基础值的最终参数，不是在上一级数值上继续连乘；未写出的参数沿用上一级。配置表保存每一级的完整快照，避免切级时遗漏此前效果。

### 基础射击：稳定处理单体

| 等级 | 候选效果 |
| --- | --- |
| Lv.1 | 每T秒朝射程内目标发射1弹，伤害D |
| Lv.2 | 单弹伤害1.20D |
| Lv.3 | 每轮连续2弹，每弹0.75D；同目标全中共1.50D |
| Lv.4 | 连续2弹，每弹0.90D |
| Lv.5 | 连续2弹，每弹D，轮次间隔0.90T |
| 进化·疾风连射 | 每轮连续3弹，每弹0.85D，轮次间隔0.90T |

连续射击为沿同一瞄准方向的独立弹体，弹间隔先试0.10秒；每个弹体可各命中一次。目标在轮次开始时确定，下一轮重新选敌。子弹之间可以触发专注；未来衍生弹不默认获得同样触发资格。T需大于本轮弹幕持续时间，避免下一轮重叠造成突发堆积。

### 穿透箭：处理成列怪群

| 等级 | 候选效果 |
| --- | --- |
| Lv.1 | 每T秒发射1路穿透箭，单目标伤害D |
| Lv.2 | 单目标伤害1.20D |
| Lv.3 | 保留原中心路线，增加一条平行侧路，每路伤害1.20D，扩大覆盖 |
| Lv.4 | 每路伤害1.45D |
| Lv.5 | 每路伤害1.65D，轮次间隔0.90T |
| 进化·交叉箭阵 | 改为正前方及左右各30度共3路，每路1.90D，轮次间隔0.90T |

同次发射用动作ID去重，同一敌人最多承受一支箭的主伤害，多路首先提高覆盖。侧路在瞄准方向两侧逐轮交替，中心路线始终保留，避免升级后原准星反而漏掉目标。沿路线仍可穿透多个不同敌人。当前穿透箭本来就是无限穿透，“穿透次数＋1”不进入卡池。默认保留角色朝向；拥有专注核心时改为朝锁定目标发射，需补瞄准接口。

### 气刃环：近身覆盖与生存配合

| 等级 | 候选效果 |
| --- | --- |
| Lv.1 | 1把环绕气刃，每个伤害周期对单目标最多造成D |
| Lv.2 | 增至2把，单次伤害仍为D，先扩大覆盖 |
| Lv.3 | 增至3把，单次伤害1.15D |
| Lv.4 | 单次伤害1.40D |
| Lv.5 | 单次伤害1.60D，伤害周期间隔0.90T |
| 进化·护身刃阵 | 6把环绕气刃，单次伤害1.85D，伤害周期间隔0.90T |

延续当前规则：同一伤害周期多把气刃命中同一敌人也只结算一次。气刃数量改善覆盖，不能按数量直接宣称单体伤害翻倍。6把刃须制作对应Prefab节点和布局；当前实现只有BladeA/B/C三个节点。旋转速度暂不单独售卖为一张升级卡。

### 小旋风：有空窗的聚怪辅助

| 等级 | 候选效果 |
| --- | --- |
| Lv.1 | 1个小旋风，持续3秒，结束后冷却5秒；中心每跳D |
| Lv.2 | 牵引速度为基础的1.15倍，中心伤害1.15D |
| Lv.3 | 牵引半径为基础的1.20倍；伤害半径不变 |
| Lv.4 | 中心伤害1.40D；牵引速度为基础的1.30倍 |
| Lv.5 | 中心伤害1.60D；结束后冷却降至4秒 |
| 进化·聚流龙卷 | 持续4秒、结束后冷却4秒；牵引半径为基础的1.40倍，中心伤害1.90D，牵引速度保持1.30倍 |

首次学习后等待5秒释放，后续升级不重置冷却、不立即补出旋风。最多同时1个；伤害半径、牵引半径、角色接触半径必须独立配置。出生位置与停止牵引半径联合标定，不能把怪物聚到角色身上。精英按阶段衰减牵引，Boss不受强制位移。

四类技能升级后，已经发出的弹体维持发射时参数；气刃从下个伤害周期使用新参数；存活旋风维持本次召唤参数，下次召唤使用新参数。进化先清理该技能旧的持续实体，再按初始释放规则启动，其他技能持续运行；不得利用选卡重复结算旧伤害。

## 4. 核心决定这局怎么打

沿用10版六枚核心，详细护盾来源上限、伤害顺序及互斥规则继续适用。本轮不再叠加技能分支，10版伤害链的“等级与分支系数”改为本表的等级/进化参数，只计算一次。

| 核心 | 主要作用 | 需要的能力 |
| --- | --- | --- |
| 破阵 | 基础射击可击中最多3个目标，穿透箭保留原穿透；两者均首目标×0.85、后续×1.10 | 前置为射击或穿透箭；弹道目标顺序、去重，与专注互斥 |
| 专注猎杀 | 弹道优先精英/Boss，连续主攻击命中每次＋5%，最高30% | 稳定锁敌、目标类别与共享层数 |
| 护体气刃 | 气刃命中获得最大生命3%的护盾，整个符文间隔1秒 | 护盾来源记录；自身贡献上限15% |
| 风眼暴露 | 中心敌人受其他技能伤害＋15%，Boss为＋7.5%；风自身伤害×0.8 | 独立风眼范围、目标易伤与伤害来源 |
| 余势 | 每击杀8只真实敌人储存一次，下一次合格的精英/Boss主伤害翻倍 | 唯一死亡事件、储备最多1次、原子消耗 |
| 稳守 | 连续5秒未受敌对有效伤害获得10%最大生命护盾 | 包含护盾受击的伤害事件；自身上限20% |

护盾共享最大生命25%的总上限。前置不满足或效果依赖尚未接入的核心不进入可玩池；设计图可以展示，但不能在游戏中发一张没有效果的卡。

**补充余势口径：** 四技能对精英/Boss的有效主伤害均可消费；射击为一发弹体、穿透箭为一个目标的一次主伤害、气刃为一个周期的一次主伤害、风为一跳。只翻倍该一次，不放大整轮。微小伤害可能抢先消费，因此必须比较三种构筑的实际贡献；若明显偏废，先调整符文本身，不能宣称所有组合都等价。

可试三种方向：

- **聚怪穿杀**：穿透箭＋小旋风＋本命允许的补位，配破阵／风眼。长于怪潮，单体爆发偏弱。
- **专注猎杀**：射击＋气刃＋补位，配专注／余势。长于精英，依赖补位清理分散怪。
- **近身守卫**：气刃＋远程输出＋补位，配护体／稳守。容错较高，需要Boss提供安全近身窗口。

本命不可卸下，示例组合必须容纳本命，不能假设所有角色都能任意拿到同一套三技能。

## 5. 普通三选一如何避免“全是废卡”

### 卡池

- 每个已学未满级技能只有一项“下一等级”，不会因拥有更多词条占据更多抽取概率。
- 只有空槽时才能出现新技能；学习时显示“占用最后一个技能槽”等提示。
- 火力：全局基础伤害加成＋8个百分点，最多3次，同类加算。
- 强健：最大生命＋初始最大生命15%，同时恢复该增量，最多3次。
- 应急恢复：恢复当前最大生命25%，只在缺血时出现；不增加上限。

### 展示规则

1. 先过滤前置、上限、互斥、满槽和无实际收益项。
2. 有可升级技能时，至少一张是已有技能升级。
3. **主修保底：** 默认主修为已学未满级技能中等级最高者；同级优先本命，再按学习先后。最近一次强化的技能若成为并列最高，则优先它。该技能连续两次普通奖励的任意展示（含刷新）均未出现，下一次普通奖励保证展示它；本次所有刷新也必须保留该项。主修改变时计数清零。
4. 有空槽且连续两次普通奖励没展示任何新技能，下次保证一张新技能；适用时与主修卡占不同位置。
5. 剩余位置无放回抽取；与已拥有核心至少匹配一个标签，基础权重1可提升至1.5，不因匹配多个标签重复相乘。有位置和合法候选时保留探索或生存选项。
6. 主修已满足“已有技能”保底，不额外占卡；合法性优先于所有展示目标。

保底统计在成功选择、消费该次奖励后更新；刷新不算新的一轮。保底是展示机会，玩家放弃卡片不获得补偿，也不保证任意选法都能在精英前满级。

不足三个有效项时展示实际数量，禁止重复卡凑数。全满且满血时显示“强化已满，继续战斗”；显式领取该次空奖励，停止将它重复入队。

### 刷新与应用

- 整局3次整组刷新；刷新必须得到不同的无序组合，保留适用保底。
- 没有其他合法组合时禁用刷新且不扣次数。
- 核心只抽合法项，首轮尽量覆盖两个不同方向；无法凑齐三项也显示实际数量。
- 点击卡后先校验并成功应用，再消费奖励、关闭面板。重复点击不能重复获得效果。
- 面板或资源缺失时保留待领取奖励并给出重试入口，不推进成已领取状态。

## 6. 经验、波次与进化时间必须一起调

首版使用**击杀直接入账经验**，不必先制作经验球和拾取系统。角色等级上限先为Lv.14，对应13次普通选择；达到上限后击杀仍计数和触发核心，不再生成普通升级。

### 一套便于试调的资源起点

- 第1～13次普通升级所需经验依次为：20、25、30、35、40、45、50、55、60、65、70、75、80。
- 前12次累计570经验，第13次累计650经验。溢出经验保留，跨多级则逐条生成奖励，不能丢失。
- 普通基础怪先为1经验；更高经验的快怪、重型怪必须从同阶段总预算扣除；精英先为20经验，首次击败只发一次。
- 最终Boss本体给结算奖励，不再触发普通升级；召唤物沿用09版“登场时冻结一份当前完整一级需求”的总经验上限。阈值递增，因此这一预算最多额外推进一级；全局13次上限仍生效。

| 检查点 | 累计普通升级目标 | 累计经验需求 | 阶段用途 |
| --- | ---: | ---: | --- |
| 0:20～0:30 | 1 | 20 | 第一次选择 |
| 1:00 | 2 | 45 | 配合首个核心理解方向 |
| 2:30精英登场前 | 5～6 | 150～195 | 集中投入者已有满级机会，分散投入者已有组合 |
| 3:30 | 8～9 | 300～360 | 争取在3:00～3:30完成一次自选进化 |
| 4:45停止普通补怪 | 12 | 570 | 完成主要构筑，准备Boss |

上表是调波次用的目标，不是按时间强制送等级。首轮可按Boss前总计570可获得经验编排，其中精英20、普通波550；召唤不计入这550。精英战期间停止新增普通怪，后续波次需承担剩余产量；4:45后清理旧怪可以补领已投放经验。

这个起点要求较高击杀完成率，**不能据此断言所有玩家能升满12次**。实际若普遍只有9～10次，先核对投放量、存活积压和停补时段，再调整阶段预算或等级门槛；不要偷偷发经验。也不能在进化后立刻按玩家强度抬高怪物生命来抵消成长。

预算示例：本命升Lv.5花4次；第二技能学习并升Lv.5花5次；第三技能学Lv.1花1次；剩2次补生命、火力或第三技能。这表示可行投入，不保证随机选择自动给出这条路线。

### 进化领取

- 精英击败只入账一枚资格；恢复与经验分别发放并去重。
- 本局第一次同时满足“持有资格＋至少一个Lv.5技能”时，排队展示所有可进化项，可选“稍后进化”；用本局提示标记确保只自动提示一次。精英先死但技能未满级时，先保留资格，直到首次有技能满级再提示。
- 玩家选暂存后保持HUD入口；玩家主动点入口可再打开。此后其他技能达到Lv.5只点亮入口，不再次自动弹窗。该规则替代09/10中达标后直接兑现的候选流程。
- 暂存入口可以在正常战斗中打开并暂停；死亡和结算后关闭。只有一个合法技能也要由玩家确认使用资格。
- 升级、核心、进化进入同一队列；当前展示先完成，之后普通升级→待处理核心→首次进化提示，共享暂停。精英未死时第二核心延后，沿用09版。
- 所有伤害、移动、召唤、计时一起暂停。死亡或结算取消剩余奖励和入口；重开完整清空本局状态。

### 代码上的具体提醒

- `MonsterCrowdController.ts` 的卡池、应用效果、击杀奖励耦合在同一控制器；不要继续把全部规则塞进去。
- `UpgradeSelectionPanel.ts` 当前要求恰好3个非空槽，并由UI随机抽取；需改为成长模块产出候选、UI只展示与回传。
- `CharacterStats.ts` 已有治疗和最大生命接口，但没有护盾；`Died`事件存在不代表死亡结算已完成。
- `CombatTypes.ts` 现有伤害信息主要是数值和技能来源；核心需要目标类型、动作ID、主/衍生标记和可追踪结果。
- `QiBladeAbility.ts` 当前只有3个刃节点，同周期对同怪去重；`PiercingArrowAbility.ts` 当前按左右方向发射；`TornadoAbility.ts` 当前牵引与伤害共用半径，生成在角色位置。上述限制不能靠改卡片文案解决。
- 卡牌显示值与真实结算使用同一份计算结果。弹速主要影响命中时机，不能按伤害提升标售；护盾触发上限和核心代价必须可见。

资源与界面后续优先使用Prefab，不用代码拼装场景节点；图片遵守PNG/JPG、真实SpriteFrame UUID、Asset DB查询及引用校验约束。此次只新增策划提案与会话中的交互示意，不改运行代码、Scene、Prefab，不新增或修改测试文件，不截图。

## 8. 推荐的开发顺序

1. **做出普通升级闭环。** 拆成长状态与配置，接3槽/5级、有效三选一、整组刷新、经验奖励队列；先让四技能普通成长真实生效，修正小旋风。
2. **补战斗依赖。** 接死亡结算、精英类别与奖励、伤害事件、护盾和锁敌；依赖完成后逐个启用核心卡。
3. **接核心与进化。** 六核心、两核心位、一枚资格、四种进化、暂存入口，统一暂停与领取。
4. **按相同预算试玩。** 检查三种构筑是否可通关、至少一套不带风、进化是否有约1分钟以上的展示机会。记录过程，不先扩大内容池。

正式实现前还需要定稿两件事：操作模式和失败判定；四技能Lv.1的基础伤害/间隔/范围及波次配表。其他本轮候选规则已写成可评审的起点，后续用实际体验修订。
