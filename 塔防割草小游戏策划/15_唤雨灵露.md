# 唤雨灵露：全屏降雨药水

设计日期：2026-09-21。

**已确认方向**：新增一种药水技能，参考用户提出的《三国战纪》“雨书”印象，使用后全屏下雨。本文围绕这个体验设计本项目的效果，不主张还原原作具体数值或机制。

**实现状态**：用户随后要求实现并放入开局药水栏，首版已于2026-09-21接入。开局第一格保留地裂、第二格加入唤雨；实现范围、素材与验证记录见[唤雨灵露](../docs/rain-potion.md)。下文保留设计过程中的候选细节，数值尚未经过实战平衡验证。现有药水规则见[药水与归梦小院](14_药水与归梦小院.md)，当前实现见[归梦小院与药水](../docs/expedition.md)。

## 1. 技能定位

- 药水名称：**唤雨灵露**；释放效果名：**暴雨天降**。
- 使用感受：天色骤暗，密集蓝白雨线从屏幕上方倾泻而下，地面不断炸开水花，屏内怪物连续受击。
- 战斗用途：被四面怪群包围时使用，在数秒内持续削减整屏敌人；使用后仍能移动、攻击和拾取。
- 与已有药水配合：风涡负责聚怪，凝霜负责冻结，地裂负责沿一个方向爆发，唤雨负责覆盖整个当前视野并持续伤害。
- 首版采用纯伤害效果，不附加冻结、牵引、击退或持续硬直；Boss可以继续行动，预警必须保持清晰。

## 2. 首版数值

| 项目 | 候选规则 |
| --- | --- |
| 起势 | 0.35秒，天色变暗、响起一声低沉雷鸣；此阶段不造成伤害 |
| 有效降雨 | 6秒 |
| 伤害节奏 | 从有效降雨开始计时，每0.5秒结算一次，共12次；第12次在6秒时结算 |
| 单次伤害 | 使用时角色攻击力的1.5倍，整次施放固定该攻击力快照 |
| 总伤害 | 同一敌人留在屏内吃满12次，为18倍角色攻击的基础伤害 |
| 普通怪／精英／Boss | 均受到常规伤害，通过现有受伤与死亡流程处理；没有额外秒杀或控制 |
| 收尾 | 0.45秒，雨线变稀、水花消散、亮度恢复；此阶段不再伤害 |
| 同时存在上限 | 1场雨，起势、降雨和收尾期间都不能重复使用；失败不消耗药水 |
| 药水操作 | 沿用使用／丢弃／取消、成功后共用1秒间隔，不占常驻技能槽 |

伤害倍率为首版试调值。它与现有风涡的持续伤害量级接近，但覆盖范围更大；后续应结合掉落频率、怪物生命和整屏清怪速度调整，不能把理论总伤害等同于实际每只怪都能吃满的伤害。

## 3. “全屏”的明确范围

- 雨幕覆盖整个当前战斗视野，HUD、药水菜单和升级界面保持清晰，画面压暗不作用于这些界面。
- 命中区域采用当前视野在战斗世界中的矩形，并限制在可战斗区域内；不能用一个超大圆替代，也不攻击屏幕外的全地图敌人。
- 每次结算时重新取得当前视野：雨随视野移动，新进入屏内的敌人从下一次结算开始受伤；已离开屏幕的敌人停止受伤。
- 敌人碰撞体与视野矩形相交即纳入，避免屏幕边缘看得见的怪物完全免伤；不以动画透明边缘判断。
- 雨滴是表现，伤害是统一的周期结算。雨线多少、水花位置、特效品质不会影响命中或伤害。
- 暂停时冻结起势、雨幕、伤害计时与收尾，雨声同步暂停；恢复后继续剩余时间，不补发暂停期间的伤害。
- 玩家死亡、结束本局、返回小院或场景销毁时，停止后续伤害、雨声和画面压暗，并回收效果。
- 空场允许使用并正常消耗；持续期间进入视野的敌人仍会受伤。

## 4. 画面与声音节奏

| 阶段 | 画面 | 声音与反馈 |
| --- | --- | --- |
| 起势0.35秒 | 战场轻微偏冷、压暗约15%；顶部浮现薄云影，第一批粗雨线落下 | 一声低沉雷鸣，启动时一次轻微震屏 |
| 降雨前段 | 蓝白斜雨迅速铺满视野，细雨与少量粗雨速度错开，落地水花开始出现 | 雨声快速淡入，怪物按统一节奏出现简短受击反馈 |
| 持续降雨 | 保持密集雨势，地面分布短促水花；角色、怪物轮廓和Boss预警清晰可见 | 一条连续雨声音轨；不为每滴雨或每个怪物叠加音效 |
| 最后一次结算 | 雨线短暂更亮，少量较大的水花强调最后一拍；仍按正常的一次伤害结算 | 一个较重的落水声，无额外伤害、闪屏或持续震屏 |
| 收尾0.45秒 | 雨幕与水花淡出，战场恢复原亮度，不保留积水遮罩 | 雨声同步淡出 |

美术方向采用项目现有的手绘奇幻风格。蓝白色水光、短而有力的水花应能在草地上辨认；避免把雨线画成激光、长冰锥或落雷。压暗幅度、雨幕透明度最终以手机上的角色和攻击预警可读性为准。

## 5. 资源与微信小游戏性能

- 图片使用现成或专门制作的美术素材，优先准备一张可平铺透明雨纹PNG、一张少帧水花图集；云影可选，首版不依赖复杂云动画。尽量不通过代码生成图片或逐帧绘制雨线。
- 建立独立效果Prefab，预置雨幕、地面水花、压暗层与音频组件。运行时复用该效果，不临时拼装整套层级。
- 雨幕优先用两层复用贴图的滚动表现远近雨，水花固定池建议上限16个；水花数量不随怪物数量增加。贴图、动画密度可以降级，伤害保持一致。
- 地面水花在角色下层，雨线在战场上层，HUD在效果上方；不采用屏幕抓取、实时折射或额外全屏模糊。
- 伤害每秒只查询2次当前可见区域，复用结果数组和稳定敌人ID；不对每一滴雨建立节点、碰撞器或执行寻敌。
- 每次结算内每个敌人最多受伤一次。整屏击杀继续走现有死亡、经验和掉落流程；伤害来源标记为药水，不消耗普攻余势。
- 飘字沿用既有容量上限，避免整屏敌人同时受伤时不断新建文字节点。
- 起势与结束使用预制音频，持续雨声只占用一个可循环声源，暂停、静音、退出和再次施放都需要正确处理；不在运行时合成声音。
- 图片禁止使用WebP，透明资源使用PNG；新增资源的尺寸、压缩后包体与实际绘制开销必须在接入后检查，不能将素材分辨率或绘制次数建议视为已测结果。
- Sprite必须绑定Asset DB确认存在的真实SpriteFrame UUID。效果保存后检查引用，完整构建后检查主包体积与微信资源格式。

## 6. 获取与界面

- 药瓶复用现有外形，以深蓝偏青的液体与水滴标识区分凝霜的浅冰蓝；药水菜单显示完整名称和文字效果。
- 仍从怪物掉落，不增加总体药水掉率。五种药水的种类权重已接入：回春40%、风涡15%、凝霜15%、地裂15%、唤雨15%，合计100%。
- 已按用户后续要求开局赠送一瓶唤雨，放在第二格，第一格保留地裂；藏露灵契的第三格留空。独立“领取唤雨”调试按钮暂未增加。
- 菜单候选文案：**唤来持续6秒的全屏暴雨，每0.5秒对视野内敌人造成150%攻击伤害。雨幕随视野移动，可边走边打；精英与Boss同样受伤，同屏最多一场雨。**

## 7. 接入验收

1. 从药水栏成功使用后只消耗一瓶；已有雨时使用第二瓶被拦截并保留，丢弃不产生效果。
2. 起势与收尾不伤害，6秒有效降雨恰好12次结算；不同帧率下没有漏算或重复结算。
3. 四角、屏幕边缘、移动后的新视野、屏外和地图外目标均按范围规则处理；改变画面长宽比不留下无雨空带。
4. 普通怪、精英、Boss正常受伤；批量死亡不因交换删除漏怪，击杀与掉落保持正常。
5. 玩家能边走边打，Boss预警、血条和药水操作不被遮挡；每滴雨没有独立命中判定。
6. 暂停后计时、动画、雨声停止，恢复不补算；死亡、回小院、重开以及连续施放不残留雨幕、声音或压暗。
7. 在项目常见与高密度怪群下对比开启前后的帧率、内存与绘制开销，完成微信真机画面和声音验收后再确定最终数值。
