# 后续开发计划

记录日期：2026-09-20

本文件保留最初的后续需求。2026-09-20随后已按用户补充细化并接入药水掉落、使用／丢弃、梦砂、三件灵契和归梦小院页面；详细规则见[药水与归梦小院](14_药水与归梦小院.md)，实施状态见[归梦小院与药水](../docs/expedition.md)。下文待细化内容以14的后续规则为准。

## 1. 已确认方向：三部分成长与使用系统

| 系统 | 规则 | 作用 |
| --- | --- | --- |
| 常驻技能 | 一部分技能保留在技能栏中，可以在局内学习、升级 | 承担日常战斗输出与持续能力 |
| 药水技能 | 另一部分技能放入独立药水栏，消耗药水才能释放，不占常驻技能位 | 在需要时使用一次技能效果 |
| 局外携带物 | 开局前选择，每局最多携带一个，效果持续整局 | 提供通用加成，让玩家选择本局侧重点 |

## 2. 药水技能

- **已确认**：区分常驻升级技能与消耗药水释放的技能，药水使用独立栏位。
- **当前倾向**：龙卷风归入药水技能，不作为占用常驻技能位的携带技能。
- **待细化**：现有小旋风及其进化形态如何迁移，其他现有技能的最终归类。寒霜、落雷等尚未确定移入药水栏。
- **待细化**：基础药水栏位数量、每栏可携带的数量、药水获取与补充方式、使用冷却及目标选择方式。
- **待细化**：药水效果的成长方式和强度。现有自动技能的伤害、持续时间与控制时间需要按消耗品的使用频率重新评估。

## 3. 局外携带物

**每局开局只选择携带一个，提供本局持续生效的通用加成。**目前明确提出的效果方向如下，具体数值待定：

| 携带效果 | 本局变化 |
| --- | --- |
| 增加移动速度 | 提高角色移动速度 |
| 增加一个药水栏位 | 在基础药水栏位之外增加1个栏位 |
| 减少技能冷却时间 | 缩短技能释放间隔，具体适用技能与幅度待定 |

以上是不同的携带选项，每局只携带其中一个，不同时获得全部效果；这些例子不限定最终选项总数，也未确定采用随机三选一。

待细化内容：

- 携带物的正式名称、获得或解锁方式，以及是否需要升级。
- 移速加成、冷却缩减的数值及叠加上限；冷却缩减是否影响药水使用冷却。
- 与现有局内核心符文的关系；尚未确定替换、合并或调整核心槽位规则。
