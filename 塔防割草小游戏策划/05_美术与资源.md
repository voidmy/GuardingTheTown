# 美术与资源

## 已确认

- 游戏为2D。
- 需要解决角色、怪物、防御塔、技能特效、界面、音效等资源来源。
- 项目由一人配合AI制作，因此资源方案必须控制数量并允许复用。

## 当前倾向的视觉方向

- Q版、休闲、易读、非血腥。
- 怪物可以采用毛团、果冻、蘑菇、甲虫、玩具或捣蛋精灵等方向。
- 敌人被击败后变成花瓣、星星、烟雾或能量粒子，不表现血液和残肢。
- 女性角色与可爱召唤物可以承担柔和、治愈的视觉吸引力。

该美术主题尚未正式锁定。

## 怪物资源压缩方案

第一版候选方案为4套普通怪动画母体＋1套独立Boss动画：

- 棉团类：普通、快速变体。
- 甲壳类：护甲、自爆变体。
- 蘑菇类：远程、治疗变体。
- 石头类：坦克、精英变体。
- Boss：独立轮廓和独立动画。

变体不能只换颜色，还应通过尺寸、轮廓、配件和动作速度让玩家一眼区分职责。

## 动画成本控制

- 如果怪物主要从上向下移动，只制作一个主要朝向。
- 行走动画控制在4至6帧。
- 攻击动画控制在3至4帧。
- 受击通过闪白、缩放和震动实现，不单独制作受击序列帧。
- 死亡使用统一粒子或溶解效果，不给每只怪制作死亡动画。
- 同骨架怪物通过配件、比例和动画速度生成变体。

## 推荐制作流程

1. 使用免费或已购买素材制作灰盒原型。
2. 确认核心玩法成立后，统一制定配色、描边、比例和阴影规范。
3. AI生成怪物概念图、配件草案和配色方案。
4. 人工选稿并修整结构，不直接采用帧间不一致的AI序列帧。
5. 将最终图拆分为头、身体、手脚和配件，制作序列帧或简单骨骼动画。
6. 制作图集、压缩纹理并进行低端手机性能测试。

## 资源授权规则

- 免费不等于可商用，下载前检查授权。
- 购买资源后保存订单、商品页截图、许可证和作者信息。
- AI资源保存生成平台、模型、日期、提示词和当时的商用条款。
- 不使用来源不明的影视、动漫、游戏角色、表情包和音乐。
- 所有正式资源登记到`资源授权登记.csv`。

## 首版资源优先级

1. 一个角色和一个本命技能的完整战斗表现。
2. 四套普通怪动画和一个Boss。
3. 基地与三种候选防御塔。
4. 符文卡片、掉落图标和最基础界面。
5. 命中、升级、清屏和Boss出现的声音反馈。
6. 其余角色和装饰内容在玩法验证后补充。
