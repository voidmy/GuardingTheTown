# Boss设计

最后整理：2026-09-07

## 1. 状态与范围

- **已确认约束**：游戏没有防御塔；Boss不依赖塔位、建造或拆塔；Boss承担构筑检验与关卡高潮。
- **本轮任务**：把讨论中的Boss与技能构筑整理成设计文档。
- **首版候选方案**：约6分钟、一只中途精英、一只最终Boss。下文名称、时间、数值和机制均为原型起点，未经过实战验证，不代表代码已实现。
- 配套规则见[技能构筑与普通升级](10_技能构筑与普通升级.md)。
- 本轮替代旧版首版方案。原12～15分钟、多精英、中途小Boss、护盾阶段与狂暴机制保留为扩展储备，首版不同时制作。

## 2. Boss的目的

1. 给本局提供明确的结束目标。
2. 让单体输出、近身防护、清理召唤物各有价值。
3. 用中途精英兑现进化资格，再给玩家时间享受成长。
4. 通过预警、应对、输出窗口，改变连续清理普通怪的节奏。

Boss不能代替普通技能平衡。如果龙卷风在普通波中无条件最优，应先调整它的获取、覆盖率和职责，不能只靠Boss免疫龙卷风解决。

## 3. 首版内容

| 对象 | 数量 | 职责 | 候选战斗时长 |
| --- | ---: | --- | --- |
| 中途精英：硬壳毛团 | 1 | 检验初步输出与躲避，发放进化资格 | 20～35秒 |
| 最终Boss：巨型毛团王 | 1 | 检验成型构筑，完成结算 | 45～75秒 |

精英不能只是换色加血，Boss不能只是放大精英。两者需要可辨识的轮廓、动作、血条和出场提示。

首版暂不加入隐藏Boss、无尽追杀者、多只小Boss、长时间无敌、护盾解谜与低血量狂暴。

## 4. 单局时间线

所有节点使用有效战斗时间。升级、核心符文、进化选择和恢复倒计时期间，角色、怪物、伤害、召唤与关卡时钟一起暂停。约6分钟指战斗时间，实际游玩会因选择耗时增加。

| 时间 | 事件 | 成长目的 |
| --- | --- | --- |
| 0:00～1:00 | 本命技能教学、基础怪潮 | 首次普通升级目标20～30秒，不给完整龙卷风 |
| 1:00 | 第一次核心符文选择 | 确定本局主要方向 |
| 1:00～2:20 | 初步组合、快速怪教学 | 为群体、单体和近身防护提供需求 |
| 2:20 | 精英预告 | 提示方向，预留准备时间 |
| 2:30 | 硬壳毛团登场 | 暂停普通波次新增，已有普通怪继续存在 |
| 精英击败后 | 发放进化资格 | 达标则进化，未达标则保留资格 |
| 3:30 | 第二次核心符文选择 | 补强或补短板；精英未死时延后至奖励之后 |
| 精英后～4:45 | 成型展示、组合压力波 | 先安排密集低血量怪，展示成长成果 |
| 4:45 | 最终Boss预告 | 停止普通波新增，提供恢复机会 |
| 5:00 | 巨型毛团王登场 | 停止普通刷怪调度，仅保留受控召唤 |
| 约5:45～6:15 | 击败Boss并结算 | 不再发放无使用机会的局内进化 |

### 调度边界

- 精英未被击败时不叠加最终Boss；延后登场并记录延后量。
- 精英超时不直接判负，也不偷偷增加玩家伤害。若常超过60秒，检查精英生命、输出窗口与成长资源。
- Boss登场前若旧怪仍多，先停补怪并留出清理阶段，不强行把新Boss与未消化的压力叠加。总时长允许因此延长，需记录。
- 5分钟不是自动胜负时限，最终Boss被击败才进入胜利结算。
- 同一帧角色死亡与Boss死亡：候选规则为Boss死亡已确认则判胜，不能由回调先后顺序决定。
- 核心选择、升级与进化进入统一队列，共享一次暂停；死亡或结算清空未处理选择。

## 5. 操作方式前提

旧文档对自由移动、守卫点切换和站桩尚未统一。下文先按可移动原型设计冲锋，但不表示移动模式已最终确认。

| 操作模式 | 合法应对 |
| --- | --- |
| 可移动 | 走出预警范围，攻击结束后接近输出 |
| 守卫点切换 | 预警只覆盖部分点位，切换冷却保证应对机会 |
| 完全站桩 | 必须先提供主动防御或其他时机决策，再围绕资源恢复与伤害设计攻击 |

禁止将移动版冲锋直接放进不能移动、没有主动防御的玩法。若最终选站桩，该机制需重新设计后验收。

## 6. 中途精英：硬壳毛团

### 战斗循环

调整位置 → 定向蓄力 → 短距离冲撞 → 停留恢复 → 重复。

| 状态 | 候选起点 | 规则 |
| --- | --- | --- |
| 登场 | 1秒 | 从合法边缘入口生成，不贴脸出现 |
| 调整位置 | 2～3秒 | 限制追击速度，不持续贴身堵住角色 |
| 预警 | 1.2秒 | 锁定路径，锁定后不追踪角色转向 |
| 冲撞 | 约0.6秒 | 同一次动作对同一角色最多造成一次冲撞伤害 |
| 恢复 | 2.5秒 | 停止主动攻击与接触伤害，给近战输出机会 |

首版仅做冲撞这一项特殊机制，不附加召唤、护盾、回血或狂暴。

### 控制与奖励

- 普通阶段牵引位移按普通怪的25%生效；蓄力与冲撞期间免疫强制位移，避免破坏预警路径。
- 正常承受直接伤害和允许的易伤效果。
- 首次击败发放1次本局进化资格及一次小额恢复，恢复先试最大生命15%，不能复活。
- 资格直接计入本局状态，无需冒险拾取。同一局只领取一次，重复死亡事件不能重复发奖。

## 7. 最终Boss：巨型毛团王

### 7.1 两个机制

只做“预警翻滚＋受控召唤”，动作串行，首版不追加第三个机制。

循环：登场 → 召唤 → 调整位置 → 翻滚预警 → 翻滚 → 恢复输出窗口 → 重复。

| 状态 | 候选起点 | 行为 |
| --- | --- | --- |
| 登场 | 1.5秒 | 顶部独立血条与名称，无登场接触伤害 |
| 召唤 | 1秒 | 生成6只基础棉团，有位置预告，不堵死全部退路 |
| 调整位置 | 2秒 | 慢速调整，建立下一次攻击的位置关系 |
| 翻滚预警 | 1.5秒 | 清楚绘制路径，锁定后不再追踪转向 |
| 翻滚 | 约0.8秒 | 按路径移动，不连续叠加碰撞伤害 |
| 恢复 | 3秒 | 静止、关闭接触伤害，气刃能安全进入有效距离 |

移动距离、碰撞宽度需按地图坐标与角色速度标定，不能直接套用未经换算的屏幕像素。

### 7.2 召唤物

- 存活上限先试12只，达到上限则跳过召唤，不生成超额单位。
- 只召唤已教学的基础棉团，不在Boss战首次介绍新怪。
- 可被旋风牵引，正常计入伤害和击杀触发。
- 每场Boss战的召唤物最多产出足够推进1次普通升级的经验：登场时锁定一份相当于当时完整一级需求的资源预算，产出扣减至零后停止给经验，不随等级重算。
- 资源耗尽后的召唤物仍有战斗功能，但不能通过拖延无限成长。
- Boss死亡先停止全部敌对伤害与召唤，再播放表现和结算；剩余召唤物随结算清理。

### 7.3 构筑兼容

| 构筑 | Boss战价值 | 必须保留的机会 |
| --- | --- | --- |
| 聚怪穿杀 | 聚集召唤物，箭矢兼顾小怪与Boss | 有召唤物发挥空间，没有长时间完全无敌 |
| 专注猎杀 | 稳定攻击Boss，在窗口内建立优势 | 锁敌规则可靠，杂兵不无条件打断锁定 |
| 近身守卫 | 恢复期贴近切割，护盾提供容错 | 恢复期关闭接触伤害，气刃实际能够命中 |

Boss不受强制位移，但正常受伤。风眼易伤对Boss按构筑文档衰减生效，不能全免疫。不给Boss添加“范围伤害无效”“气刃无效”等限制。

### 7.4 数值标定

先以同等升级预算的3种构筑记录有效输出，再调整生命，不先指定一个缺乏依据的固定血量。

- 45～75秒是目标窗口，不要求所有构筑击杀时间一致。
- 翻滚候选伤害为无局外加成基准角色最大生命的20%～25%，不随本局堆高生命同步增长。
- 一个动作的接触、翻滚、持续碰撞不能叠成预期外秒杀。
- 不根据本局构筑实时缩放Boss生命，避免抵消玩家选对升级的优势。
- 经常超过90秒时检查生命、锁敌、输出窗口和技能可达性；首版不新增隐藏秒杀计时器。

## 8. 进化资格兑现

1. 中途精英给予1枚本局资格。
2. 已有Lv.5技能时，由玩家从达标技能中选一个进化，消耗资格。
3. 未达标则保存，显示“已获进化资格：将任一技能升至Lv.5”。
4. 后续达到Lv.5，在同一次升级暂停中兑现；不重打精英、不再抽随机材料。
5. 多技能达标不能按数组顺序自动选择。
6. 进化替换原技能，占原技能槽，不额外占核心符文位。
7. 每局仅此1次进化，其他Lv.5技能仍保持完整基础形态。

最终Boss提供结算与后续解锁展示，不再提供局内技能。局外奖励与商业化另行定义。

## 9. 实现边界

- 敌人提供类别、控制系数、受伤状态和奖励领取标记。
- Boss使用明确状态机：预警、攻击、恢复、死亡互斥，暂停恢复后不跳错状态。
- 波次调度切换普通、精英、Boss阶段，停止现有循环补怪对Boss阶段的干扰。
- 伤害、护盾、易伤和锁敌与普通战斗共用规则，避免重复实现。
- 本体、预警和血条优先用Prefab及编辑器配置，遵守真实资源UUID和引用校验要求。
- 角色死亡、胜利结算、奖励发放各有唯一入口，禁止重复触发。

## 10. 验收与观察

本轮仅写文档；后续按项目要求手动试玩和记录必要日志，不新增或修改测试文件，不默认截图。

- 3种构筑同等投入下都能打过精英和Boss，记录技能、核心、进化时间及战斗用时。
- 预警可读，离开范围后不会被延迟碰撞击中。
- 近战在恢复期能输出，无需持续受伤换伤害。
- 风可以处理小怪且对Boss有有限收益，不能全程控制Boss。
- 选择期间所有战斗计时暂停，恢复后没有积压攻击瞬间结算。
- 进化资格不丢失、不重复；死亡与击杀同帧时结果一致。
- 无法无限刷召唤经验；结算后无残留攻击、伤害或升级弹窗。

## 11. 待验证与扩展储备

待验证：操作模式、6分钟是否有足够展示时间、精英与Boss数值、恢复量、首次通关解锁。

原方案储备：若未来扩展12～15分钟，可考虑额外精英和中途小Boss；巨型毛团王的召唤破盾、低生命狂暴、分阶段攻击均留到基础双机制稳定之后。召唤型、护盾型、分裂型、远程预警型可作为后续Boss方向，不纳入本轮首版。
