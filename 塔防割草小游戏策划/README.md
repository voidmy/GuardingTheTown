# 塔防割草小游戏策划

最后整理：2026-09-07

本目录用于保存目前关于小游戏的策划结论。为了避免把讨论建议误当成正式决定，各文件统一使用以下状态：

- **已确认**：已经由项目发起人明确提出或确认。
- **当前倾向**：方向基本合适，但还需要原型或数据验证。
- **候选方案**：讨论中产生的设计，尚未正式确定。
- **待确认**：会明显影响开发范围，需要后续决定。

## 文件目录

- `01_核心玩法.md`：产品方向、操作方式和首版范围。
- `02_角色与技能.md`：四个角色方向及其技能草案。
- `03_符文与掉落.md`：局内三选一与战场掉落系统。
- `04_怪物与刷怪.md`：怪物职责、波次和刷新节奏。
- `05_美术与资源.md`：怪物、美术、动画及资源获取方案。
- `06_平台与商业化.md`：微信、抖音与广告变现方向。
- `07_待确认清单.md`：下一步必须做出的设计决定。
- `08_市场割草游戏技能与局内体验.md`：主流割草游戏的技能、升级路线、局内差异化与单局时长参考。
- [09_Boss设计.md](09_Boss设计.md)：约6分钟首版候选、中途精英、最终Boss、进化奖励与战斗验收。
- [10_技能构筑与普通升级.md](10_技能构筑与普通升级.md)：4个基础技能、成长分支、6个核心符文、随机保底、3种构筑与实现规则。
- `资源授权登记.csv`：保存购买、下载和AI生成素材的来源与授权信息。

## 当前一句话概念

一款面向微信和抖音小游戏的2D休闲割草游戏：玩家每局选择一名自带本命技能的角色，通过自动战斗、升级选择和核心符文形成不同构筑。

## 本轮方案与旧文档关系

- 已确认没有防御塔；早期文档的建塔、塔位、强化防御塔内容仅作历史记录，不进入当前实现。
- 本轮Boss与构筑讨论整理在09、10两份文档，具体规则与数字为首版候选，需要原型验证。
- 约6分钟为本轮短局原型；08中的12～15分钟属于早期完整局参考，不与本轮时间线同时执行。
- 02保留未来角色概念；10中的4个基础技能指当前可复用的战斗能力，不表示新增4个角色。
- 操作方式、基地是否作为独立受击目标、商业化与局外解锁仍需另行统一；本轮Boss以角色受击与存活为战斗设计基础。
