# 市场割草游戏技能与局内体验参考

> 本文档是对市面上“幸存者-like / 割草”游戏的设计归纳，用于后续方案讨论，不代表项目已确认采用全部内容。

最后整理：2026-08-31

## 一、市场常见技能类型

| 类型 | 常见表现 | 主要升级维度 |
| --- | --- | --- |
| 弹射类 | 子弹、飞刀、箭矢、魔法球 | 数量、穿透、弹射、射速、追踪 |
| 近战类 | 横斩、旋转、冲刺斩、震地 | 范围、连击、击退、暴击、吸血 |
| 范围类 | 火圈、毒池、落雷、陨石、冰风暴 | 范围、持续时间、触发频率、区域数量 |
| 环绕类 | 飞剑、护盾球、旋转锯 | 环绕数量、转速、半径、击退 |
| 召唤类 | 宠物、炮塔、无人机、分身 | 数量、攻速、属性继承、合体进化 |
| 状态类 | 燃烧、中毒、流血、冰冻、感电、易伤 | 层数、持续时间、传播、引爆、处决 |
| 防御类 | 护盾、回血、吸血、闪避、护甲、复活 | 容量、恢复速度、减伤、触发频率 |
| 触发类 | 暴击落雷、击杀爆炸、受伤反击 | 触发率、冷却、连锁次数 |
| 功能类 | 拾取范围、经验增益、幸运、移动速度 | 经济成长、掉落品质、刷新次数 |
| 主动大招 | 冲刺、全屏攻击、时间停止、变身 | 充能、冷却、范围、无敌时间 |

## 二、常见升级路线

### 2.1 线性等级强化

最容易理解的基础路线：

```text
获得技能
→ 伤害提高
→ 数量增加
→ 范围增加
→ 冷却缩短
→ 增加穿透或弹射
→ 满级
```

线性升级适合用于前期建立成长感，但不应成为全局唯一内容，否则每局体验容易趋同。

### 2.2 武器＋被动＝进化

《吸血鬼幸存者》采用的经典结构：

```text
基础武器升至满级
＋ 获得对应被动物品
＋ 获得宝箱
＝ 进化武器
```

进化应尽量赋予新机制，例如吸血、无限穿透、状态传播或大范围爆炸，而不只是增加伤害。

示例：

```text
火球 Lv.8 + 燃烧核心 = 爆炎陨星
飞刀 Lv.8 + 攻速手套 = 无限刀阵
冰环 Lv.8 + 持续时间被动 = 永冻领域
```

### 2.3 分支或超频

技能在关键等级选择不同改造方向：

```text
普通火球
├─ 连射：高攻速、多弹道、低单发伤害
├─ 爆破：低攻速、大范围、击杀爆炸
└─ 燃烧：低直接伤害、叠层、传播和引爆
```

分支必须改变使用方式或战斗节奏，才能产生真正的局内差异。

### 2.4 装备、商店和品质合成

《Brotato》代表的波次商店结构：

```text
波次战斗
→ 获得材料
→ 商店购买武器和道具
→ 同名武器合成更高品质
→ 围绕角色特性堆叠属性
```

这种结构的主要决策来自资源分配、商店刷新、武器组合和属性取舍。

### 2.5 标签联动

为技能设置“火焰、冰霜、投射物、召唤、近战、持续伤害”等标签，通过标签建立联动：

```text
燃烧敌人死亡 → 产生爆炸
爆炸命中 → 传播燃烧
燃烧达到10层 → 自动引爆
引爆后 → 降低火焰技能冷却
```

标签联动可以让有限技能产生更多有效组合，是建立“Build成型后突然起飞”体验的主要手段。

### 2.6 局外永久成长

常见内容包括：

- 全角色基础属性成长。
- 新角色、武器、地图和难度解锁。
- 角色专属天赋树。
- 武器熟练度、锻造和永久超频。
- 初始装备、重抽、锁定、放逐等Build控制能力。
- 通过挑战、成就或任务解锁新内容。

## 三、常见成型Build

- **投射物流**：数量 → 攻速 → 穿透 → 弹射 → 暴击触发。
- **范围轰炸流**：范围 → 冷却 → 持续时间 → 多区域 → 连环爆炸。
- **元素异常流**：叠加燃烧或中毒 → 状态传播 → 层数增伤 → 满层引爆。
- **召唤流**：召唤数量 → 攻速 → 继承人物属性 → 合体或复制。
- **近战吸血流**：范围 → 攻速 → 护甲 → 吸血 → 低血增伤。
- **反伤坦克流**：生命 → 减伤 → 恢复 → 受击反击 → 伤害按生命缩放。
- **控制处决流**：冰冻或眩晕 → 易伤 → 延长控制 → 对受控目标处决。
- **经济滚雪球流**：前期经验、幸运和掉落 → 增加选择机会 → 后期转化为战斗力。

## 四、每局体验不同的实现方式

### 4.1 使用“受控随机”，不使用纯随机

局内升级通常每次只展示3个选项，但需要通过规则控制选项质量：

- 已获得技能的强化选项具有更高权重。
- 尽量保证至少出现一个能加强当前Build的选项。
- 连续多次未出现核心技能时，逐步增加其权重。
- 向玩家提供刷新、锁定、放逐和跳过功能。
- 获得火焰、召唤等核心标签后，提高对应联动的出现权重。
- 尽量不让完全不兼容的升级污染选项池。

设计目标是让玩家感觉自己正在构筑Build，而不是被随机结果完全控制。

### 4.2 用技能栏上限制造取舍

技能栏通常限制在4～6个。玩家不能取得全部技能，获得新技能与强化已有技能之间存在明确的机会成本。

### 4.3 同一技能提供不同分支

有效的分支应影响战斗距离、走位方式、清怪节奏或搭配技能。如果两个分支只是伤害增加比例不同，玩家通常不会认为它们是不同体验。

### 4.4 使用“固定时间节奏＋随机内容”

关卡需要保持可设计的节奏，同时保留随机变化：

```text
第3分钟：固定出现精英，精英类型随机
第6分钟：固定出现事件，事件内容随机
第9分钟：固定高压怪潮，怪物组合随机
最终阶段：固定出现Boss，Boss技能组或关卡词缀可变
```

可以用于制造变化的内容包括：

- 敌人组合和出生方向。
- 精英、Boss、宝箱的具体类型。
- 神坛、商人和临时事件。
- 地图障碍、危险区域和可破坏物。
- 敌人加速、精英增多、治疗降低等本局规则。
- 提高敌人强度以换取更高奖励的风险选项。

### 4.5 通过局外解锁改变后续内容池

随着角色、技能、进化、地图事件和难度的解锁，第1局与第20局面对的内容池可以自然不同。

需要注意：可解锁技能越多，随机池越容易稀释，因此中后期需要标签筛选、重抽、锁定和放逐系统配合。

## 五、市场常见单局时长

| 产品结构 | 常见单局时长 |
| --- | ---: |
| 轻量移动端、小游戏 | 8～15分钟 |
| 快节奏幸存者游戏 | 10～20分钟 |
| 标准完整局 | 20～30分钟 |
| 波次＋商店结构 | 20～30分钟 |
| 无尽或高难模式 | 30分钟以上 |

市场产品示例：

- 《20 Minutes Till Dawn》主打10～20分钟快速对局。
- 《Brotato》完整局低于30分钟，单波约20～90秒，中间穿插商店。
- 《Halls of Torment》采用约30分钟的完整局。

## 六、对当前项目的候选建议

### 6.1 单局时长

当前项目面向微信和抖音小游戏，完整局可以优先验证12～15分钟：

```text
0～2分钟：获得核心攻击手段，看懂角色特性
2～5分钟：选择Build方向
5～8分钟：形成第一个技能联动
8～11分钟：技能进化，进入爽感峰值
11～13分钟：高压怪潮
13～15分钟：最终Boss与结算
```

如果符文三选一会暂停战斗，玩家实际操作时长可能达到15～18分钟。

### 6.2 成长节奏

- 每30～60秒出现一次有效选择。
- 每2～3分钟出现一次明显的战斗质变。
- 一局至少安排三次可感知的成长跨越：
  1. 由弱变为可以稳定清理怪物。
  2. 核心联动成型，清怪效率明显提升。
  3. 最终进化或终极技能完成，进入本局爽感顶峰。

### 6.3 技能等级结构

首版可以优先考虑“每个技能5级＋中途分支＋满级质变”：

```text
Lv.1：获得技能
Lv.2：数值强化
Lv.3：二选一机制分支
Lv.4：强化已选分支
Lv.5：满足标签或被动条件后进化
```

这种结构能保留割草游戏的低理解成本，同时让同一技能产生不同Build，首版不需要一开始就制作数百个技能。
