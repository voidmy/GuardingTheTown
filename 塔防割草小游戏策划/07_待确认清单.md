# 待确认清单

以下决定会显著影响开发量，建议按顺序逐项确认。

## 第一优先级：原型规则

- [ ] 最终采用完全站桩、三个守卫点切换，还是小范围自由移动？
- [ ] 首个原型使用罡气角色还是连线角色？
- [ ] 角色攻击和防御塔之间的关系是什么？
- [ ] 防御塔由玩家建造、自动生成，还是只做固定塔位升级？
- [ ] 单局目标时长是3分钟、6分钟还是8至10分钟？
- [ ] 第一张地图有几个怪物入口和几条路线？

## 第二优先级：成长系统

- [ ] 一局进行几次符文三选一？
- [ ] 是否提供免费刷新，是否允许广告刷新？
- [ ] 通用符文与角色专属符文各占多少？
- [ ] 掉落技能是自动发动、点击发动还是选择目标后发动？
- [ ] 是否存在局外永久成长？

## 第三优先级：内容范围

- [ ] 四个角色的正式名称、外形和最终本命技能。
- [ ] 第一版实际上线一个角色还是四个角色？
- [ ] 第一版怪物题材和美术风格。
- [ ] 第一版防御塔数量。
- [ ] 第一版普通关卡数量和Boss数量。

## 第四优先级：平台经营

- [ ] 微信和抖音哪个先首发？
- [ ] 是否坚持纯广告变现，还是预留后续混合变现？
- [ ] 主体、软著和备案由谁负责办理？
- [ ] 是否准备短视频素材生产流程？

## 建议的下一步

先只确认一个3分钟灰盒原型：一个角色、一种基础怪、一种快速怪、一只精英、一条路线、三次成长选择和一个最终Boss。该原型只验证核心战斗是否让玩家愿意立即再开一局，不提前扩展角色和长期养成。
