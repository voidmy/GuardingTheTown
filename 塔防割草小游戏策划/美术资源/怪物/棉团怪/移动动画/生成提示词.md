# 生成提示词

为 2D 手机休闲小游戏生成一张横向排列的四帧移动动画精灵表：一只向右移动的“棉团怪”，身体是薄荷绿色的圆形棉花团，有两只很短的脚、两片叶子形耳朵和简单可爱的表情。采用清晰粗轮廓、平涂色彩、少阴影和低细节，保证缩小到 64 × 64 像素时依然易于识别，适合同屏大量出现。

四帧依次表现：触地、身体向下挤压、另一只脚触地、身体略微向上伸展；脚步交替、身体轻微弹跳，并能从第四帧平滑循环回第一帧。四帧必须保持角色造型、颜色、线条粗细、光照、比例和朝向一致，处于相同大小的方形单元格内，完整显示且互不重叠。

使用真正透明的背景并保留 Alpha 通道；不要地面、阴影、边框、辅助线、标签、文字、水印、额外角色、武器或粒子特效。
